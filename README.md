# 💬 Customer Service Chatbot

An interactive NLP-based Customer Service Chatbot built using Streamlit and Scikit-learn.
The chatbot uses TF-IDF Vectorization and Cosine Similarity to understand user intent and provide intelligent FAQ-based responses.

---

## 🚀 Features

- Interactive real-time chat interface
- NLP-powered intent matching
- TF-IDF Vectorization
- Cosine Similarity-based response selection
- Adjustable similarity confidence threshold
- Chat history using Streamlit session state
- Expandable NLP debugging insights

---

## 🧠 Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- TF-IDF Vectorizer
- Cosine Similarity

## ▶️ How to Run

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2️⃣ Navigate to the Project Folder

```bash
cd Customer-Service-Chatbot
```

### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the Streamlit App

```bash
streamlit run app.py
```
